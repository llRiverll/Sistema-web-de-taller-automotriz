# 🚗 Sistema Web de Gestión Automatizada para Taller Automotriz

Este proyecto es un sistema web integral diseñado para la automatización, seguridad y gestión de los procesos operativos de un taller automotriz. Desarrollado como proyecto de grado, su objetivo es optimizar el control de inventario y facilitar la toma de decisiones mediante la generación de reportes precisos.

## ✨ Características Principales

* **🔐 Seguridad y Autenticación:** Módulo de login seguro con control de acceso y roles de usuario.
* **📦 Gestión de Inventario:** Control, seguimiento y administración estructurada del stock de repuestos y materiales del almacén.
* **📊 Generación de Reportes Automáticos:** Exportación dinámica de datos operativos y de inventario directamente a formatos Excel para auditorías y control administrativo.
* **💻 Interfaz Moderna:** Diseño frontend intuitivo y amigable para facilitar la experiencia del usuario.

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python
* **Base de Datos:** SQL 
* **Frontend:** HTML5, CSS3, JavaScript
* **Reportes:** Librerías de Python para exportación a Excel.

## 🚀 Arquitectura y Desarrollo
Este sistema fue construido enfocándose en código limpio, escalabilidad y buenas prácticas de desarrollo. Se implementó una arquitectura modular que permite separar la lógica de negocio de la interfaz de usuario, garantizando un mantenimiento eficiente.
